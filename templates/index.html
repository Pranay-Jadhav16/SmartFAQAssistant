ℹ️ Project Architecture & Methodology

About Smart FAQ Assistant

An AI Agent-Based Question Answering System built for the B.Tech Computer Science AI Agent Development (AIAD) practical curriculum.

🔬

Deterministic Retrieval-Based Architecture

100% Offline • Zero Hallucinations • scikit-learn TF-IDF

Smart FAQ Assistant is an agentic question-answering system designed around deterministic information retrieval. Instead of using a generative Large Language Model (LLM) that can hallucinate unverified policies or incur recurring API charges, this agent converts student questions into vector space representations using Term Frequency-Inverse Document Frequency (TF-IDF) and computes geometric semantic alignment using Cosine Similarity.

Cosine Similarity Formula: CosSim(Q, D) = (Q • D) / (||Q|| × ||D||)

Agent Decision Pipeline

1 Input Processing

Sanitization & Contraction Expansion

Converts text to lowercase, handles apostrophes and contractions ("don't" → "do not"), strips excessive punctuation, and rejects empty strings or symbol-only queries.

2 Intent Extraction

Category Intent Matching

Analyzes lexical cues to identify relevant campus departments (Admissions, Academics, Examinations, Library, Fees, Facilities) or applies explicit student filter constraints.

3 Vector Similarity

TF-IDF Matrix & Cosine Metric

Computes sparse vectors using sublinear TF scaling and smooth IDF weighting. Scores candidate FAQ vectors against the query vector in milliseconds.

4 Decision Gate

Configurable Confidence Fallback

If highest candidate score ≥ threshold (0.25), delivers the verified SQLite answer. If below threshold, cleanly diverts to official department contacts.
